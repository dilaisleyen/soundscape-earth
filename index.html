About & sources

Map: NASA's Scientific Visualization Studio, Sea Surface Temperature (SST) Anomaly – Near Real Time (SVS #5176). Visualizer: Kel Elkins (USRA). Scientist: Atousa Saberi (NASA/GSFC). Data: JPL MUR SST analysis (PO.DAAC).

This page shows the most recent frame that was available when it was downloaded, on 14 November 2026; it does not update by itself. 0 °C means “same as normal”; the source page does not state which reference period “normal” is based on. Values are read from the colours of the picture, so they are approximate, and the colour scale ends at ±4 °C.

Country names: Natural Earth (public domain), Admin 0 – Countries, 1:50m, naturalearthdata.com. They are a label layer only: the sound and the values never use them. The place named for the pointer is approximate: a country is named only when it is clearly the closest one, otherwise the continent is named.

Earth Jukebox is a prototype made for the NASA International Space Apps Challenge 2026. It is not an official NASA website, and NASA does not endorse this project.
